ShortsMaker

**Проект демонстрирует навыки анализа данных и работу с Python и Pandas.**

Описание

ShortsMaker — инструмент для обработки видео и аудио с целью выявления ключевых моментов.  
Проект акцентирует внимание на работе с данными: сбор, очистка, агрегация и анализ текстовой информации с помощью Pandas и Python.

Основные шаги анализа данных:

- Конвертация видео в аудио и нормализация через FFmpeg (`video_to_audio.py`).  
- Разделение аудио на сегменты и получение расшифровки через Whisper (`whisper.ipynb`).  
- Сбор и объединение CSV-файлов с текстовой информацией с последующей очисткой через Pandas.  
- Анализ текста для выявления ключевых и интересных моментов.  
- Формирование тайм-кодов для нарезки видео (`video_shorting.py`).  

Проект показывает умение **обрабатывать данные, объединять и анализировать большие объёмы информации, работать с Python и Pandas**, а также применять навыки программирования для практических задач.

---

Структура проекта

- `main.py` — основной скрипт для запуска обработки.  
- `downloader.py` — загрузка видео и аудио.  
- `video_to_audio.py` — конвертация видео в аудио и нормализация.  
- `video_shorting.py` — нарезка видео по тайм-кодам.  
- `whisper.ipynb` — блокнот с обработкой аудио и анализом текста через Pandas в колабе.  
- `requirements.txt` — список зависимостей для Python.
